Anthropic API Key
Stored in this browser only (localStorage) — it is never written into this file or into any test you generate. Get one at console.anthropic.com.
Test Source
Choose where the passages come from. Convert is the old behaviour — you paste a real Cambridge/ETS test and the machine rebuilds it. Author writes a brand-new, original test from scratch, so you never have to hunt for source material.
Question Types
Leave on Auto for an authentic Cambridge-style mix (each passage gets 3–4 different task types). Or pick specific types to drill one skill — useful when the lesson is about Matching Headings, for example. Diagram/map labelling is excluded: an AI-written passage has no figure.
Topic Memory nothing generated yet
Every passage written in Author mode is remembered in this browser and sent to the AI as a do-not-repeat list, so tests made weeks apart stay different. It does not follow you to another laptop — use Export/Import to sync GG1 and GG2, and export now and then in case browsing data gets cleared.
Reasoning Effort (cost vs accuracy)
Sonnet 5 defaults to high effort and thinks before answering — those reasoning tokens are billed as output. Passage writing is always set to low (creative prose gains little from deliberation). This control applies to the step that writes and solves the questions, where reasoning is what keeps the answer key right.
